# البنية التقنية للمنصة

## الواجهة

موقع ثابت يعمل على GitHub Pages، مكتوب بـ HTML وCSS وJavaScript دون إطار ثقيل. يدعم العربية RTL والجوال والكمبيوتر والتثبيت كتطبيق PWA.

## قاعدة البيانات

Supabase/PostgreSQL يحفظ الحسابات والأسئلة والمحاولات والتشخيصات والاحتياجات والدورات والإعلانات. الواجهة لا تحتوي على كلمة مرور قاعدة البيانات ولا مفتاح إداري.

## الحماية

- Row Level Security على جميع الجداول.
- العضو يرى بياناته الشخصية فقط.
- المشرف يرى المؤشرات والطلبات ويحدث حالتها.
- المدير يدير المحتوى والصلاحيات.
- الإجابة الصحيحة لا تصل إلى المتصفح قبل إرسال الاختيار؛ التحقق يتم داخل دالة قاعدة البيانات.

## التحديث اللحظي

تستمع لوحة المشرف لتغيرات طلبات الاحتياج ومحاولات التدريب، ثم تحدث مؤشرات الصفحة دون الحاجة إلى إعادة فتح المنصة.

## نمط المعاينة

عندما يكون `DEMO_MODE: true` تعمل نسخة محلية وتحفظ البيانات في متصفح الجهاز. هذا مفيد للعرض فقط، وليس بديلًا عن الربط بقاعدة البيانات المشتركة.
