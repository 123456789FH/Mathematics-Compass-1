# بوصلة رياضيات ١ — منصة تشغيلية

منصة عربية RTL لأعضاء ملتقى الرخصة المهنية رياضيات ١، تعمل بواجهة ثابتة على GitHub Pages وبقاعدة بيانات ومصادقة عبر Supabase.

## ما يعمل فعليًا بعد الربط

- إنشاء حساب وتسجيل دخول واستعادة كلمة المرور.
- ثلاثة أدوار: عضو، مشرف، مدير منصة.
- تشخيص من ١٠ أسئلة مع حفظ النتيجة وبصمة المهارات.
- بنك أسئلة لا يكشف الإجابة الصحيحة قبل الإرسال.
- تسجيل كل محاولة ووقت الإجابة ونسبة الدقة.
- إرسال احتياج العضو ومتابعة حالته.
- لوحة مشرف تجمع عدد الأعضاء والاحتياجات ومعدلات الخطأ.
- تحديث لحظي للوحة المشرف عند وصول احتياج أو محاولة جديدة.
- إضافة الأسئلة والدورات والإعلانات وتعديلها من داخل المنصة.
- إدارة أدوار الأعضاء وترقية المشرفين من حساب المدير.
- استعادة كلمة المرور وتعيين كلمة جديدة من رابط البريد.
- تصدير احتياجات الأعضاء بصيغة CSV.
- سياسات Row Level Security لحماية بيانات كل عضو.
- تطبيق ويب تقدمي PWA قابل للتثبيت.

## الملفات المهمة

```text
index.html                  الواجهة
css/app.css                 التصميم المتجاوب
js/app.js                   منطق الواجهة والتفاعل
js/supabase-backend.js      الاتصال التشغيلي بقاعدة البيانات
js/demo-backend.js          معاينة محلية قبل الربط
js/seed-data.js             بيانات العرض التجريبي
js/config.js                رابط Supabase والمفتاح العام
database/01_schema.sql      الجداول والسياسات والدوال
database/02_seed.sql        المهارات والأسئلة والدورات الأولية
database/03_promote_admin.sql ترقية حسابك إلى مدير
.github/workflows/pages.yml نشر GitHub Pages آليًا
```

## التشغيل السريع

اقرئي: `docs/دليل_التشغيل_الكامل.md`

المنصة تفتح افتراضيًا في وضع تجريبي حتى تضاف بيانات Supabase إلى `js/config.js`. لا تضعي مفتاح `service_role` في ملفات GitHub مطلقًا؛ المطلوب فقط المفتاح العام Publishable أو Anon مع تفعيل سياسات RLS الموجودة في المشروع.

## الحسابات التجريبية

في الوضع التجريبي يوجد زران للدخول كعضو أو مشرف. البيانات تحفظ في متصفح الجهاز فقط وليست مشتركة بين الأعضاء.
